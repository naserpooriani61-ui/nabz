شروع کار

۱. ورود

با نام کاربری و رمز وارد شوید. اگر اولین ورود است، سیستm باید رمز را تغییر دهد.

۲. خانه (Dashboard)

بعد از ورود، داشبورد مخصوص نقش شما نمایش داده می‌شود:

  • پرستار: بیماران بخش، MAR نزدیک، ویتال بحرانی
  • سرپرستار: آمار تیم، درخواست‌ها، compliance
  • پزشک: بیماران سرویس، راند، مشاوره
  • مترون: همه بخش‌ها، بحران‌ها، درخواست‌ها
  • مدیر: کاربران، دسترسی‌ها، سیستم

۳. دسترسی سریع

در پایین صفحه ۵ تب اصلی:

تبکاربرد
🏠 خانهداشبورد نقش
🚨 اورژانستریاژ، کد، MCI
🩺 بالینیبیماران، ویتال، کاردکس، MAR
🧠 عصبیموتور عصبی، cohort
☰ منوهمه پنل‌ها

کارهای روزانه پرستار

ثبت ویتال

  1. پنل «بیماران» → کلیک روی بیمار
  2. دکمه «ثبت ویتال» یا از منو
  3. مقادیر را وارد کنید — NEWS2 خودکار محاسبه می‌شود
  4. اگر NEWS2 ≥ ۷، هشدار فوری ارسال می‌شود

توزیع دارو (MAR)

  1. پنل MAR — سه تب: در نوبت / دیرکرد / پرخطر
  2. روی دوز کلیک → ۵ Rights را تیک بزنید
  3. داروهای High-Alert نیاز به شاهد دارند
  4. PRN بعد از ۱ ساعت نیاز به ثبت اثربخشی دارد

تحویل شیفت

پنل «تحویل شیفت — پرستاری» → بیمار → «📝 تولید ISBAR» → امضا → گیرنده تأیید می‌کند

کارهای روزانه پزشک

ثبت دستور

  1. بیمار → «دستور جدید»
  2. یا از Order Set آماده استفاده کنید
  3. سیستم تداخل دارویی و آلرژی را چک می‌کند

مشاوره

درخواست مشاوره → انتخاب سرویس + نوع (اورژانسی/فوری/روتین) → ارسال

ترخیص

  1. ترخیص → «ترخیص پیشرفته»
  2. Med Rec، Readmission Risk، Follow-up، Teach-back را انجام دهید
  3. Checklist JCI را کامل کنید
  4. سند انتقال PCP تولید کنید

مدیریت

افزودن کاربر

مدیریت → «کاربران» → ➕ جدید → نام کاربری، رمز، نقش، بخش

تخصیص بخش

مدیریت → «مدیریت بخش کاربران» → هر کاربر را یک بخش اختصاص دهید

On-Call

مدیریت → «On-Call Board» → دکمه «🚀 خودکار پر کن»

عیب‌یابی

اگر صفحه خالی بود: بخش (ward) شما تعریف نشده — با مدیر تماس بگیرید
اگر login خطا داد: رمز اشتباه یا حساب غیرفعال است
اگر SSE قطع شد: صفحه را refresh کنید
اگر داده قدیمی: Ctrl+Shift+R برای hard refresh

# NABZ — Neural Hospital Operating System

سیستم عامل بیمارستانی عصبی (NABZ)

یک سیستم مدیریت بیمارستانی کامل که در Termux / Node.js توسعه داده شده است.

## ویژگی‌های اصلی

- مدیریت بیماران، تخت‌ها، ویزیت‌ها و پرونده‌ها
- بخش اورژانس، اتاق عمل، پرستاری
- سیستم شیفت و نیروی انسانی پیشرفته (Shift Assistant)
- CDSS (سیستم پشتیبانی تصمیم بالینی)
- مدیریت کیفیت، ایمنی، آموزش
- پنل‌های مختلف بر اساس نقش کاربر
- پشتیبانی از حالت آفلاین و PWA

## ساختار پروژه

```
nabz/
├── core/           # هسته سیستم (سرور، احراز هویت، دسترسی‌ها، state machine و ...)
├── modules/        # ماژول‌های مختلف سیستم (بالینی، اورژانس، پرستاری و ...)
├── public/         # فرانت‌اند (HTML, CSS, JS)
├── data/           # داده‌های JSON (بیماران، کاربران، تخت‌ها و ...)
├── tools/          # ابزارهای کمکی
├── backups/        # پشتیبان‌ها
├── package.json
└── ...
```

## پیش‌نیازها

- Node.js نسخه ۲۰ یا بالاتر
- Termux (روی اندروید) یا هر محیط لینوکسی

## نصب و راه‌اندازی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور
npm start

# یا حالت توسعه (با watch)
npm run dev
```

سپس مرورگر را باز کنید و به آدرس `http://localhost:PORT` بروید  
(پورت معمولاً در `core/server.js` مشخص شده است).

## توسعه

- برای اضافه کردن ماژول جدید، فایل را در پوشه `modules/` قرار دهید.
- تغییرات مهم را همیشه با Git ثبت کنید.

## وضعیت فعلی

برای دیدن وضعیت فعلی پروژه، باگ‌ها و کارهای باقی‌مانده به فایل `PROJECT_STATUS.md` مراجعه کنید.
